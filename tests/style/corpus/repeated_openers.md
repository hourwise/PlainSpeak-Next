# Platform overview

The system provides a single place to manage every account. The system enables
teams to share records without copying them. The system ensures that changes are
recorded against the person who made them.

The system supports single sign-on through the existing directory. The system
allows administrators to define roles at the team level. The system offers an
audit trail covering the previous twelve months.

The platform connects to the reporting warehouse each night. The platform
retains raw events for ninety days. The platform exposes an interface for
extracting data on demand.

The platform handles authentication for every connected service. The platform
manages certificates automatically. The platform delivers notifications through
the existing channels.
