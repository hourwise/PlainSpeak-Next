# Service standards

We answer telephone calls within three rings during published opening hours. If
a call cannot be answered we return it before the end of the next working day.

We reply to written enquiries within ten working days of receipt. If a full
answer will take longer we send an acknowledgement explaining the delay.

We process applications within fifteen working days of the closing date. If a
decision will take longer we write to the applicant with a revised date.

We publish decisions on the register within five working days. If a decision is
subject to appeal we note that on the entry at the same time.

We review complaints within twenty working days of receipt. If the review will
take longer we write to the complainant explaining what remains outstanding.

We update guidance within one month of any change in the rules. If the change is
urgent we publish a notice before the guidance itself is revised.

We report performance against these standards every quarter. If a standard has
been missed we set out the reason and the action being taken.

We consult on changes to these standards every second year. If a change is
proposed we allow eight weeks for responses before deciding.

We record every contact against the relevant case file. If a contact relates to
more than one case we record it against each of them separately.

We destroy records six years after a case is closed. If a case is subject to
legal proceedings we retain the records until those conclude.
